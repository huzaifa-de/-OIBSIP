# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project explores a retail sales dataset using Python to understand sales performance, customer demographics, product-category performance, and relationships between numerical variables.

## Dataset
- File: `dataset/retail_sales_dataset.csv`
- Records: 1,000
- Columns: Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis and Visualizations
The `charts/` folder contains the following generated visualizations:

1. **Monthly Sales Trend** — `monthly_sales_trend.png`
2. **Quarterly Sales Trend** — `quarterly_sales_trend.png`
3. **Customer Age Distribution** — `customer_age_distribution.png`
4. **Gender Distribution** — `gender_distribution.png`
5. **Top Selling Categories** — `top_selling_categories.png`
6. **Revenue by Category** — `revenue_by_category.png`
7. **Correlation Heatmap** — `correlation_heatmap.png`
8. **Average Customer Spending** — `average_customer_spending.png`

## How to Run
1. Clone or download the repository.
2. Open the project folder in Jupyter Notebook or JupyterLab.
3. Install the required libraries if needed:
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```
4. Open `Retail_Sales_EDA.ipynb` and run the cells.
