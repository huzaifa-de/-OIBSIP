
# 📊 Retail Sales Data – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a Retail Sales Dataset using Python.

The main objective is to analyse retail sales transactions, understand customer purchasing behaviour, identify sales trends, evaluate product category performance, and generate actionable business insights.

The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data analysis and visualisation.

## 🎯 Project Objectives

- Understand the structure and characteristics of the dataset.
- Identify and handle missing values and duplicate records.
- Perform descriptive statistical analysis.
- Analyse monthly and quarterly sales trends.
- Explore customer demographics based on age and gender.
- Identify top-selling products or product categories.
- Analyse revenue generated by product categories.
- Examine correlations between numerical variables.
- Generate actionable business recommendations.


### Step 4: Launch Jupyter Notebook
